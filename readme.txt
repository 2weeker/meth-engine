a frameworkless and javascriptless textboard engine inspired by the now defunct ratwires.space

~~ built in pure go ~~

TEXT EFFECTS
------------

  >text           greentext (start of a line)
  <text           bluetext (start of a line)
  >>123           link to post 123
  **text**        bold
  *text*          italic
  `text`          code
  ==text==        red
  %%text%%        spoiler
  $text$          rainbow
  $$text$$        shake
  ^^text^^        3D
  !!text!!        glow
  [[text]]        button
